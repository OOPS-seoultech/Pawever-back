# 굿즈 자료 보관 정책 대조와 결정 기록

작성일: 2026-09-19  
상태: **결정 완료 — 2차 기획을 기준으로 반영함.**

## 확정 기준

- 2차 기획 PRD R15를 기준으로 고객 사진·출력 도면/4면도·3D 렌더·원본 모델/3MF와 상세주소는 **배송 완료일로부터 3개월** 보관한다.
- 3개월은 한국 시간(`Asia/Seoul`)의 달력 월이다. 배송 완료 시 `deleteAfter`를 이 규칙으로 기록하며, 90일로 근사하지 않는다. `src/main/resources/application.yaml`, `GoodsSurveyFulfillment#markDeliveryCompleted` 참조.
- 매일 실행되는 보관 작업은 `deleteAfter`가 지난 주문의 비공개 고객 사진을 저장소에서 삭제하고, 상세주소를 제거한다. 확정 제작 자료도 같은 `deleteAfter` 기준으로 삭제한다. 주문·결제·공급 계약 기록은 별도 5년 보존 경로다.
- 현재 AS grant는 보관 시계를 멈추지 않는다. 이미 `deleteAfter`가 지난 주문에는 자료 목록이나 새 링크를 발급하지 않는다. `AsCaseService#retained` 참조.

## 기존 주문 정렬

- `V28__align_active_goods_retention_to_calendar_months.sql`은 아직 보관 중인 주문의 `delete_after`만 달력상 3개월 기준으로 다시 계산한다.
- 이미 파기된 사진·상세주소·제작 자료를 복원하지 않으며, 과거 주문을 즉시 삭제하지도 않는다.
- 운영 반영 전 백업과 복제 DB dry-run으로 대상 건수와 SQL 실행 결과를 확인한다.

## 범위 밖 보존

- 주문·결제·공급 계약 기록은 법정 보존 기준 5년을 유지한다. 사진·상세주소·제작 자료와 분리한다.
- AS 48시간 열람 권한은 보관 기간과 독립적이며, 만료된 권한이 자료를 삭제하지 않는다.
